# 👔 Typescript/Javascript Instructions

## JavaScript is PROHIBITED

Use of untyped JavaScript is **prohibited** for ALL new code, even if existing code is untyped. If you are modifying an existing JavaScript file, convert it to Typescript first.

## Additional contexts

- [typescript-coding-conventions](contexts/conventions.md) Describes fundamental rules for ALL code generation in TypeScript, regardless of the size or complexity of the codebase. **Read** this file if you are writing ANY TypeScript code, even if it is code in the design phase.
- [typescript-engineering](contexts/engineering.md) Describes how to implement advanced software engineering conventions specifically in TypeScript. **Read** this file if you are generating/fixing/modifying non-trivial TypeScript code, writing tests, or ingesting external data.
- [typescript-new-project-rules](contexts/new-project.md) Describes additional rules to follow when creating a new TypeScript project, or adding tooling to an existing project. **Read** this file if you are generating/fixing/modifying code related to project setup, configuration, or tooling.
